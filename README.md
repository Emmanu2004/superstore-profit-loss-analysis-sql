# superstore-profit-loss-analysis-sql
📊 Superstore Profit & Loss Analysis using SQL
Project Overview

This project analyzes retail sales data from a Superstore dataset to identify profit drivers, loss-making categories, discount impact, and regional performance. The objective was to use SQL for data cleaning, 
exploratory data analysis, and business insight generation.

Business Problem

The company wanted to understand:

Which categories and products generate the most profit
Which categories are causing losses
Whether high sales always lead to high profit
The impact of discounts on profitability
Regional performance differences
Dataset Information
Dataset: Superstore Sales Dataset
Records Analyzed: 9,000+ transactions
Tools Used:
MySQL
SQL
Excel
